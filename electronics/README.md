# Electronics Workspace

Planned V1 electronics:

- 2-channel surface EMG acquisition
- MCU
- 3 motor drivers with current sensing
- encoder inputs
- physical grip selector
- hard motor-disable path
- battery voltage / temperature monitoring
- protected power distribution

Bench prototypes can use development boards. The mature wearable revision should reduce connector count and use strain relief, proper grounding, serviceable harnesses and protected battery wiring.
