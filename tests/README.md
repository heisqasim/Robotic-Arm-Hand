# Test Workspace

Every major design revision should produce evidence, not only photos.

Recommended records:

- `mechanical/` - cycle count, grip force, tendon wear, failure photos
- `electrical/` - current, temperature, battery and fault tests
- `emg/` - calibration repeatability and command accuracy
- `fit/` - anonymous comfort/fit observations kept private if patient-derived
- `environment/` - heat, sweat/splash and dust tests

Public test data must not contain patient-identifying information.
